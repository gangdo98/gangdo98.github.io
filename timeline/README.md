# 타임라인 🗓️

집·토실이·회사·가족·친구의 **지난 기록과 앞으로의 예정**을 한곳에 모은 가족 타임라인. 2026년 10월부터 2027년 12월까지 15개월을 분기 달력과 월별 리스트로 봅니다.

- 배포: https://gangdo98.github.io/timeline/
- 포털: https://gangdo98.github.io/ (`토실이 방` 아래 4번째 배너)

## 보는 방법

- **분기 달력** (기본): `26-4Q` ~ `27-4Q` 5개 분기 탭. 분기마다 달력 3개가 나오고, 기록·예정이 있는 날에는 테마 색 점(●)이 붙습니다. 오늘은 진한 초록으로 강조되고, 점이 있는 날짜를 누르면 그 날의 상세 카드가 달력 바로 아래에 열립니다.
- **월별 리스트**: `26.10` ~ `27.12` 15개월을 세로로 이어 봅니다.
- **필터**: 테마(전체·집·토실이·회사·가족·친구)와 상태(전체·기록·예정)를 달력과 리스트 모두에 바로 적용합니다.
- **후속 예정**: `[기록 완료]` 카드 안에 `↳ 후속 예정`으로 다음 할 일과 날짜를 짝지어 둡니다.

## 기록 추가하기

`data/timeline.json`의 `items`에 한 줄 추가하고 `updated` 날짜를 바꿉니다.

```json
{
  "id": "2026-12-31-example",
  "date": "2026-12-31",
  "theme": "home",
  "status": "planned",
  "title": "제목",
  "memo": "한 줄 메모",
  "detail": "접어 두는 자세한 내용 (선택)",
  "endDate": "2027-01-02",
  "precision": "month",
  "follow": [
    { "text": "다음 할 일", "date": "2027-01-10" },
    { "text": "날짜가 없으면", "when": "12월 중" }
  ]
}
```

- `theme`: `home` · `tosil` · `work` · `family` · `friends`
- `status`: `done`(기록 완료) · `planned`(예정)
- `endDate`: 여러 날에 걸친 일 (여행 등). 달력에 기간 전체 점이 찍힙니다.
- `precision: "month"`: 날짜가 아직 없고 달만 정해진 일 (`date`는 그 달 1일로 두고 카드에는 `날짜 미정`으로 표시).

## 개인정보

공개 저장소입니다. **본명·동호수·전화번호·예약번호·계정 ID는 넣지 않습니다.** `토실이`, `아내`, `단지 하자소송 세대 현장조사`처럼 부르는 말로만 적습니다.
